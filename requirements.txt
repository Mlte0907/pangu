# 盘古 — Python 核心依赖
# ======================
# 默认安装这一份即可运行完整的记忆服务（REST API + MCP + ONNX 本地嵌入）。
#
# 设计要点：**核心清单不含 torch / sentence-transformers / chromadb / openai-whisper**。
# 这些包的代码路径全部是惰性导入（逐项说明见 pyproject.toml 的 multimodal 组注释），
# 且会传递引入约 1.3GB 的 CUDA 轮子（nvidia-cudnn 620MB / nvidia-cublas 517MB /
# triton 216MB）——在无 GPU 的 aarch64/CPU 机器上永不执行，纯属浪费。
#
# 实测对比（aarch64，无 GPU）：
#   本清单            → 56 包 / 236MB / 约 20 秒
#   含 torch 的完整集 → 下载 987MB+ 仍未落盘，耗时 1.5 小时以上
#
# 需要图像 / 音频 / 备用嵌入能力时（可选组见 pyproject.toml）：
#   pip install -e ".[multimodal]"
# 无 GPU 机器建议先装 CPU-only 轮子，可省下全部 CUDA 负载：
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
