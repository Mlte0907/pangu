### 4.1 数据获取

```typescript
// 侧边栏数据
const fetchSidebarData = async () => {
  const [stats, health, performance] = await Promise.all([
    remote.pangu.stats(),
    remote.pangu.healthCheck(),
    remote.pangu.getPerformanceStats(),
  ])
  return { stats, health, performance }
}

// 知识图谱数据
const fetchKnowledgeGraph = async () => {
  const graph = await remote.pangu.exportGraph()
  return graph // { entities: [...], relations: [...] }
}

// 记忆图谱数据
const fetchMemoryGraph = async (wing?: string) => {
  const memories = await remote.pangu.listMemories({ wing })
  const connections = await remote.pangu.getMemoryConnections()
  return { memories, connections }
}
```

### 4.2 实时更新

使用轮询或 WebSocket 实现数据实时更新：

```typescript
// 每 30 秒刷新侧边栏
useEffect(() => {
  const interval = setInterval(fetchSidebarData, 30000)
  return () => clearInterval(interval)
}, [])

// WebSocket 订阅记忆事件
useEffect(() => {
  const ws = new WebSocket('ws://127.0.0.1:19529/ws')
  ws.onmessage = (event) => {
    const data = JSON.parse(event.data)
    if (data.type === 'memory/added' || data.type === 'memory/updated') {
      refreshGraph()
    }
  }
  return () => ws.close()
}, [])
```

## 8. 风险和注意事项

1. **性能**: 大型知识图谱（>1000 节点）可能影响渲染性能，需要实现虚拟化
2. **安全性**: API 密钥存储需要加密，不能明文存储在配置中
3. **兼容性**: 需要确保与现有 Agent Teams UI 不冲突
4. **离线模式**: 盘古服务不可用时需要优雅降级
